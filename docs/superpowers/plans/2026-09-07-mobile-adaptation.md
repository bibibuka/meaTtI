# План реализации мобильной адаптации сайта maeTtI (без рабочего стола)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Полная мобильная адаптация шапки, навигации, главной страницы, услуг, кейсов, контактов, политики и футера под мобильные экраны (320px–480px).

**Architecture:** Перевод ключевых компонентов на Mobile-First подход: полноэкранный overlay меню с безопасными зонами, адаптивная высота шапки (h-16 на мобилке, h-24 на десктопе), возврат скрытых цен на мобильных устройствах, изолированный скролл чипов категорий в кейсах, перенос элементов управления модальной галереи для удобного тача, чистый вертикальный поток без срезов и наложений.

**Tech Stack:** Next.js 16, React 19, Tailwind CSS 4, Framer Motion.

---
