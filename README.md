# maeTtI — сайт студии

Next.js 16 со статическим экспортом (`output: "export"`). Сайт не собирает персональные данные: вместо формы заявки страница «Контакты» открывает Telegram с готовым сообщением, отправляет его сам посетитель.

## Разработка

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
```

## Выкладка на хостинг (Apache)

1. `npm run build` — готовый сайт появится в `out/`. Сборка автоматически исправляет пути сегментов Next в Windows-экспорте; `npm run check:export` проверяет их перед выкладкой.
2. Залить содержимое `out/` в корень сайта, включая скрытый `.htaccess`. PHP не нужен — сайт полностью статический.
3. Проверить: прямая ссылка `/uslugi` открывается, несуществующий адрес отдаёт страницу 404, кнопка на `/contacts` открывает Telegram с текстом.

Посмотреть собранный сайт локально: запуск `meaTtI-prod` в `.claude/launch.json` (`node scripts/serve-out.mjs`, порт 3100).

Адрес в `robots.txt` и `sitemap.xml` — `https://maetti.ru`; другой домен задаётся переменной `SITE_URL` при сборке. Редирект на HTTPS в `public/.htaccess` закомментирован: включите его, если хостинг не делает этого сам.

## GitHub Pages

Каждый пуш в `main` собирает копию сайта на GitHub Pages (путь `/meaTtI`). Копия закрыта от поисковиков (`noindex`).
